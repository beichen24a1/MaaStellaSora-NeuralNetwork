# 音符／协奏联合决策研究

离线实验模块：保留冻结 beta 的普通潜能选牌能力，新增双输出网络，学习商店与事件中潜能、音符和金币的取舍。它不注册 Maa 回调，也不更改插件当前默认模型。

## 价格污染：旧结果已作废，正在重训

协作者指出原始价格 OCR 把 90/45、90/72 拼成 9045、9072。已确认冻结商品统计有 293/4,772 条错误价格，且进入训练特征和联合标签生成环境。

**旧 `joint_v2` 的 +1.85 结果不能作为正确价格环境的提升证据。** 训练集有 47 个根局面、256 条动作行直接带坏价格特征；更完整的续局影响范围未记录，必须整批重新生成标签。

已修正为合法数量／价格组合，添加拒绝异常价档的校验和回归检查。当前活动版本是 `joint_v3_prices_clean`；重新训练、选择修正强度和独立评测尚在进行，新结果完成前不推荐引用任何提升数字。

详细证据和修复方式见 [PRICE_AUDIT.md](PRICE_AUDIT.md) 与 [价格修复审计](data/price_audit.json)。

## 运行

在仓库根目录执行。推理和评测只需要 NumPy；只有训练需要 PyTorch。

```bash
python -m pip install numpy
python -m unittest discover -s research/concerto_joint -v
python research/concerto_joint/infer.py research/concerto_joint/runs/joint_v3_prices_clean/example_public_state.json
python research/concerto_joint/evaluate.py
```

评测默认使用已发布面板：每配置 32 局，敏感性条件每配置 8 局，种子 `20401107`。

重新生成联合标签、训练、选择修正强度并评测：

```bash
python -m pip install -r research/concerto_joint/requirements.txt
python research/concerto_joint/run_experiment.py
```

已生成的标签可加 `--reuse-data` 复用。首次生成需要执行数千次 CPU 续局；训练自动选择可用的 CUDA，否则使用 CPU。训练标签和根局面文件被 `.gitignore` 排除，不依赖原始玩家日志。

## 模型与接口

`JointEpisode` 提供完整离线对局及可序列化公共快照。音符购买与饮料、强化、刷新共用一个钱包，饮料和音符总共最多八个货架格。分支从公共后验重新采样隐藏状态；特征不读取实际环境 RNG 或隐藏计数。

`JointCritic` 的两个输出分别学习普通潜能收益修正、协奏收益修正。公共音符规则作为初始先验，网络可以改变其动作排序；修正强度只用开发对局选择，不使用最终测试对局。普通选牌继续由冻结 beta 完成；终局音符调整采用所有策略共用的固定贪心算子，尚未训练调整策略本身。

`infer.py` 接收完整公共 JSON 快照，返回动作及候选排序。当前要求 13 种音符库存全部已知；不能把未知库存补成零。

研究教师固定在 [models/ordinary_beta_20261105.npz](models/ordinary_beta_20261105.npz)，与插件当前 `models/beta.npz` 的版本不同。保留旧教师是为了复现本次结果，不能直接用新教师替换后沿用成绩。模型会核对教师、规则代码和输入文件的哈希；文本哈希统一规范化 CRLF/LF，支持不同平台检出。

## 建模范围与假设

- 客户端快照提供 150 组逐技能门槛；61 件双协奏秘纹与技能 ID、辅助供给完成匹配。单协奏或无协奏秘纹未纳入首版训练面板。
- 沿用上游冻结的 45 节点潜能路线，不添加“补足到 53 个免费页面”等额外路线。
- 战斗默认每场八枚音符，在当前塔九种音符中均匀抽样，与选中的秘纹需求无关。完整音符轨迹不足，尚未识别真实条件分布；另测每场四枚、十二枚。
- 饮料货架沿用内核，剩余格补音符。商品大小与价格来自 4,772 条音符商品观察，种类均匀生成；原观察混合来源且含重复货架，不是 4,772 个独立成交样本。
- 音符事件采用显式表效应和均匀随机音符，部分事件暴露全部建模选项；实际可见选项抽样和部分奖励细节仍未确定。
- 终局最多十五次一换一调整，允许转向所需类型；实际时机、合法目标仍需证据，另测完全关闭调整。
- 优化协奏等级，不建模角色触发条件及真实战斗伤害。

上述不确定机制都属于实验假设。改动转移规则、目标或特征后，应重新生成联合标签、训练并评测，不能仅修改旧标签的版本号。
